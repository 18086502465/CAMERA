### 1.2 相机缺陷映射粒度

采用相机级 1 对 1 映射：

```text
工厂 + 产线 + 工位 + 相机 + sourceCode + 生效时间段 => 标准缺陷类型
```

默认规则：

- 允许不同相机的 `p0` 对应不同标准缺陷类型。
- 如果同一相机检测不同产品，允许升级为 `产品 + 相机 + sourceCode` 的产品专属映射；产品专属映射优先于相机通用映射。
- 同一相机、同一生效时间段内，`p0` 只能对应一个标准缺陷类型。
- 同一相机、同一生效时间段内，一个标准缺陷类型只能被一个 sourceCode 绑定。
- 历史数据保存映射快照，配置变更不影响历史统计口径。

### 1.3 未配置编码处理

默认策略：接口失败并记录映射异常。

- 相机上报 `p9` 等未配置编码时，接口返回 `422`。
- 不自动创建缺陷类型。
- 不自动归类为“其他”。
- 记录映射异常，前端“产线统计”和“系统配置 > 相机缺陷映射”提供处理入口。

### 1.4 计数模式

P0 只支持增量计数：

```text
counterMode = INCREMENTAL
```

说明：

- `summary.totalCount / okCount / ngCount` 表示本批次新增数量。
- `defects[].count` 表示本批次各缺陷新增数量。
- 暂不启用累计模式，避免相机重启、计数器清零导致重复或漏计。

### 1.5 缺陷类型配置字段

标准缺陷类型默认包含：

| 字段 | 说明 |
|---|---|
| 缺陷编码 | 系统内部稳定编码 |
| 缺陷名称 | 页面展示名称 |
| 缺陷类别 | 胶滴、污点、接头等 |
| 默认缺陷位置 | 前腰、后腰、内装、复合区等 |
| 默认严重度 | HIGH / MEDIUM / LOW |
| 是否计入 NG | 默认计入 |
| 排序 | 页面展示和动态表格列顺序 |

### 1.6 动态报表权限

默认权限：

| 角色 | 权限 |
|---|---|
| 管理员 | 新增、编辑、删除、保存全局报表 |
| 普通用户 | 查看报表、调整临时筛选，不保存布局 |

### 1.7 报表保存范围

P1 默认按工厂保存一套默认看板。

后续可扩展：

- 按用户保存个人看板。
- 按角色保存看板模板。
- 按产线保存专项看板。

### 1.8 图表刷新频率

默认刷新策略：

| 页面/模块 | 刷新策略 |
|---|---|
| 相机状态 | 10-30 秒自动刷新 |
| 图像记录 | 手动刷新 + 上传后可刷新 |
| 产线统计 | 1 分钟自动刷新，可手动刷新 |
| 历史长周期图表 | 手动刷新 |

### 1.9 图表钻取能力

P1 默认支持：

- 点击图表 → 查看对应明细数据。
- 点击相机/工位维度 → 跳转图像记录并带入筛选条件。
- 点击映射异常 → 跳转系统配置 > 相机缺陷映射。

### 1.10 导入模板字段

相机缺陷映射导入模板默认包含：

| 字段 | 必填 | 说明 |
|---|---:|---|
| factoryName | 是 | 工厂名称 |
| lineName | 是 | 产线名称 |
| workstationName | 是 | 工位名称 |
| cameraCode | 是 | 相机编号 |
| productName | 否 | 产品名称；为空表示相机通用映射 |
| sourceCode | 是 | 相机上报编码，如 p0/p1 |
| defectCode | 是 | 标准缺陷编码 |
| defectName | 否 | 标准缺陷名称，辅助校验 |
| positionCode | 否 | 默认缺陷位置 |
| severity | 否 | 默认严重度 |
| effectiveStart | 是 | 生效开始时间 |
| effectiveEnd | 否 | 生效结束时间，空为长期有效 |

## 5. 评审确认结果
