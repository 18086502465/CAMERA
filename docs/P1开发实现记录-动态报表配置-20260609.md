# P1 开发实现记录：产线统计动态报表配置

更新时间：2026-06-09  
实现范围：产线统计页动态图表配置闭环（新增 / 编辑 / 删除 / 默认看板 / 页面持久化）

## 1. 本次实现目标

进入 P1 阶段后，优先完成“产线统计动态报表配置”的可用闭环：

- 产线统计页从固定图表改为基于看板配置动态渲染。
- 支持默认看板自动创建。
- 支持从组件库添加图表。
- 支持编辑图表名称、图表类型、统计指标、宽度、高度、排序和是否跟随全局筛选。
- 支持删除图表，删除不影响历史检测数据。
- 支持页面刷新后保留图表配置。

## 2. 后端接口实现

后端控制器：

- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\controller\LineAnalyticsController.java`

新增动态报表配置接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/analytics/dashboards` | 查询看板列表 |
| GET | `/api/v1/analytics/dashboards/default` | 查询默认看板；不存在时自动创建 |
| GET | `/api/v1/analytics/dashboards/{id}` | 查询看板详情 |
| POST | `/api/v1/analytics/dashboards` | 新建看板 |
| PUT | `/api/v1/analytics/dashboards/{id}` | 更新看板 |
| DELETE | `/api/v1/analytics/dashboards/{id}` | 软删除看板和下属图表 |
| GET | `/api/v1/analytics/dashboards/{id}/widgets` | 查询看板图表 |
| POST | `/api/v1/analytics/widgets` | 新建图表 |
| PUT | `/api/v1/analytics/widgets/{id}` | 更新图表 |
| DELETE | `/api/v1/analytics/widgets/{id}` | 软删除图表 |
| POST | `/api/v1/analytics/widgets/reorder` | 保存排序和布局 |

依赖表：

- `cfg_analytics_dashboard`
- `cfg_analytics_widget`

默认看板组件：

1. 核心质量指标
2. 30分钟质量趋势
3. 缺陷类型排行
4. 异常工位排行
5. 产品缺陷透视表

## 7. 2026-06-09 深夜增强补充

本次继续完成 P1 第二切片，并修复“产线统计页面新增图表保存体验异常”的问题。

### 7.1 新增 / 优化能力

- 报表拖拽布局：
  - 画布中的图表卡片支持拖拽改变顺序。
  - 拖拽完成后调用 `POST /api/v1/analytics/widgets/reorder` 保存排序和布局。
- 图表拉伸大小：
  - 图表卡片右下角增加拖拽拉伸手柄。
  - 支持 6 / 12 栅格宽度和 2~5 行高度。
  - 拉伸完成后自动保存 `layout_json`，刷新页面后保持。
- ECharts 标准图表：
  - `trend`：标准折线图，展示检测总数、NG 数、良率。
  - `defectRanking`：横向柱状图，展示缺陷类型 Top。
  - `stationRanking`：横向柱状图，展示异常工位 Top。
  - `cameraRanking`：横向柱状图，展示异常相机 Top。
  - `stackDefectBySeverity`：堆叠柱状图，按 HIGH / MEDIUM / LOW 堆叠。
- 图表独立筛选：
  - 新增 / 编辑图表时可关闭“跟随顶部筛选”。
  - 独立筛选支持产品、相机、缺陷类型、严重度。
  - 独立图表会单独请求 `GET /api/v1/analytics/line-summary`。
- 日聚合 / 异步聚合任务：
  - 新增 `POST /api/v1/analytics/aggregation/daily/run`。
  - 新增 `GET /api/v1/analytics/aggregation/jobs/recent`。
  - 自动创建日聚合表 `agg_quality_day`、`agg_defect_type_day`。
  - 当前为手动触发异步任务，后续可接入定时任务。
- 多看板模板管理：
  - 支持看板模板列表、新建、编辑、删除。
  - 支持按工厂读取默认模板。
