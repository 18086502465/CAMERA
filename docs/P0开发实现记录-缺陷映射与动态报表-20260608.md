### 1.2 后端

已重构新版检测上报接口：

- `POST /api/v1/camera/inspection/batch-upload`

关键实现：

- 只支持 `INCREMENTAL` 增量计数。
- 校验 `schemaVersion=2.0`、Token、`X-Device-Id`、相机、产品、计数一致性。
- 按 `产品 + 相机 + sourceCode` 查询映射，产品专属优先，通用映射兜底。
- 未映射编码返回 HTTP `422`，并写入 `fact_inspection_mapping_exception`。
- 重复 `camera_id + batch_id` 按幂等返回，不重复入库。
- 成功后写入检测批次、缺陷计数，并同步更新 30 分钟聚合表。

新增配置接口：

- `GET/POST/PUT/DELETE /api/v1/config/products`
