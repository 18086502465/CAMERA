## 2. 当前交付版本边界

本批文档以当前代码与发布包为准，覆盖：

- 前端：`frontend`，Vue 3 + Vite + Element Plus + ECharts。
- 后端：`fact-product`，Spring Boot 2.7.15 + MyBatis-Plus + MySQL。
- 数据库：`wms-new`，SQL 文件：`wms-new-20260531-new.sql`。
- 发布：`build-release.ps1` + Inno Setup + Windows 服务包装器。
- 运行入口：`TCP 8091` 同时提供页面访问和相机接口上报。
- 数据源：相机心跳、相机检测批量上报、缺陷图片批量上传。

## 3. 关键运行约束

- `TCP 8091`：页面访问 + API 上报。
- `TCP 3306`：仅本机 MySQL 使用，默认不建议对外开放。
- 图片和日志写入安装目录外部配置路径，不写入 jar 内部。
- 前端 dist 已集成进 Spring Boot，目标电脑无需单独启动 Node/Vite。
- 安装包已内置 JRE，目标电脑仍需安装 MySQL 8.0 并导入数据库。
