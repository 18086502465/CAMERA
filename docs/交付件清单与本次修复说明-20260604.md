# 产线缺陷在线AI检测系统交付件清单与本次修复说明（2026-06-04）

## 1. 本次修复范围

### 1.1 Windows 服务启动修复

问题：安装后启动 Windows 服务时报错：`java.exe not found. Please install JDK/JRE 8+ or package jre directory.`

修复：
- 发布脚本 `build-release.ps1` 默认把本机构建环境中的 Java Runtime 打包到发布目录：`jre/bin/java.exe`。
- Windows 服务包装器启动时优先使用安装目录下的 `jre/bin/java.exe`。
- 新电脑安装后不再依赖系统 PATH 或 JAVA_HOME。

### 1.2 缺陷图片上传接口数量限制

接口：`POST /api/v1/defect-images/upload`

本次规则：
- 单批次最大支持 100 张图片。
- 后端配置项：`defect-image.max-batch-images: 100`。
- multipart 单文件默认最大 10MB。
- multipart 总请求默认最大 1024MB。
- `files`/`file` 实际上传数量超过 100：直接返回失败。
- `metadata.images` 声明数量超过 100：直接返回失败。
- 建议设备端/调用方增加请求头：`X-Image-Count: <图片数量>`；当该值超过 100 时，服务端可在 multipart 解析前直接返回 413，避免继续接收完整图片流。

错误示例：

```json
{
  "code": 500,
  "message": "单批次最多支持 100 张图片，当前请求声明 101 张；请拆分为多个批次后重试",
  "data": null
}
```

### 1.3 图像记录页面优化

修复内容：
- 图像记录页新增搜索框。
- 支持按相机名称、设备编号、工位、文件名、拍摄时间搜索。
- 相机对象改为一行展示一个，避免两列布局导致信息拥挤。
- 保留单相机展开历史记录分页。
- 保留图片弹窗上一张/下一张切换。

## 4. 安装与启动要点

1. 先安装 MySQL 8.0。
2. 导入数据库 `wms-new`。
3. 运行安装包，安装过程中选择：
   - 软件安装目录。
   - 工作路径：用于日志、图片上传和运行数据。
4. 安装完成后访问：

```text
http://localhost:8091
```

5. 相机接口上报地址示例：

```text
http://<server-ip>:8091/api/v1/camera/status/heartbeat
http://<server-ip>:8091/api/v1/camera/inspection/batch-upload
http://<server-ip>:8091/api/v1/defect-images/upload
```
