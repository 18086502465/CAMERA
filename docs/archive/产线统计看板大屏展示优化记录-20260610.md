# 产线统计看板大屏展示优化记录

更新时间：2026-06-10

## 1. 需求背景

默认产线统计看板除了配置态，还需要一个最大化 / 大屏展示交互，便于直接展示已经配置好的图表，用于现场大屏、会议汇报和巡检查看。

## 2. 本次实现

前端文件：

- `D:\45344\0004-软件源码\frontend\src\views\stats\LineAnalyticsView.vue`

新增能力：

1. 顶部新增 `看板大屏` 按钮。
2. 动态报表画布新增 `大屏展示` 按钮。
3. 每个图表卡片新增 `最大化` 按钮。
4. 大屏模式只展示配置好的图表，不展示组件库、编辑、删除、拖拽等配置操作。
5. 大屏模式保留核心 KPI：检测总数、OK数、NG数、良率、缺陷数。
6. 大屏模式支持：
   - 刷新数据
   - 单图放大
   - 从单图返回整屏
   - 退出大屏
7. 大屏图表复用当前动态看板配置和图表数据，包括：
   - 核心质量指标
   - 趋势折线
   - 缺陷类型排行
   - 异常工位排行
   - 异常相机排行
   - 缺陷严重度堆叠
   - 产品缺陷透视表
   - 映射异常明细
