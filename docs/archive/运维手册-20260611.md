# 产线缺陷在线AI检测系统 - 运维手册

版本：2026-06-11

## 1. 部署架构

```text
Windows 电脑
├─ MySQL 8.0
│  └─ 数据库：wms-new
└─ 相机检测系统服务
   ├─ Spring Boot 后端
   ├─ Vue 前端静态页面
   ├─ 外部配置 application.yml
   ├─ 图片上传目录
   └─ 日志目录
```

默认端口：

- TCP 8091：页面访问 + 相机接口上报。
- TCP 3306：本机 MySQL 使用，默认不建议对外开放。

## 3. 数据库初始化

### 3.1 非重置增量初始化

用于已有库补齐系统设置中心等增量表：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\45344\0004-软件源码\scripts\database-init.ps1
```

### 3.2 全新库/测试库重置初始化

会执行最终模型脚本，具有破坏性，仅用于全新环境或已确认可重置的测试库：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\45344\0004-软件源码\scripts\database-init.ps1 -ResetSchema
```

## 4. 数据库备份

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\45344\0004-软件源码\scripts\database-backup.ps1
```

默认备份目录：

```text
D:\45344\runtime\db-backups
```

建议：

- 每次升级前手工执行一次备份。
- 每天夜间通过 Windows 任务计划程序执行一次备份。
- 备份文件至少保留 7~30 天，具体按现场要求执行。

## 5. 数据库恢复

恢复具有覆盖风险，必须显式追加 `-Force`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\45344\0004-软件源码\scripts\database-restore.ps1 -BackupFile D:\45344\runtime\db-backups\wms-new-backup-YYYYMMDD-HHMMSS.sql -Force
```

恢复前必须：

1. 停止系统服务。
2. 备份当前数据库。
3. 确认恢复文件来自可信来源。
4. 恢复完成后启动服务并执行上线验收脚本。

## 6. 服务启动和停止

### 6.1 停止服务进程

```powershell
Get-CimInstance Win32_Process -Filter "name='java.exe'" |
  Where-Object { $_.CommandLine -like '*time-bucket-demo.jar*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

### 6.2 启动服务

```powershell
$java='D:\45344\0000-jar\CameraDetectionSystem\jre\bin\java.exe'
$jar='D:\45344\0004-软件源码\fact-product\target\time-bucket-demo.jar'
Start-Process -FilePath $java `
  -ArgumentList @('-Dapp.home=D:/45344/0000-jar/CameraDetectionSystem/runtime','-jar',$jar) `
  -WorkingDirectory 'D:\45344\0004-软件源码\fact-product' `
  -WindowStyle Hidden
```

## 7. 构建发布

### 7.1 前端构建

```powershell
cd D:\45344\0004-软件源码\frontend
npm run build
```

### 7.2 同步前端到后端 static

```powershell
$frontendDist = Resolve-Path 'D:\45344\0004-软件源码\frontend\dist'
$staticDir = Resolve-Path 'D:\45344\0004-软件源码\fact-product\src\main\resources\static'
Get-ChildItem -LiteralPath $staticDir.Path -Force | Remove-Item -Recurse -Force
Get-ChildItem -LiteralPath $frontendDist.Path -Force | ForEach-Object {
  Copy-Item -LiteralPath $_.FullName -Destination $staticDir.Path -Recurse -Force
}
```

## 10. 运维风险提示

1. 不建议将 MySQL 3306 对外开放。
2. 上传图片目录应放在安装目录外部可配置目录，并纳入磁盘容量监控。
3. 清空操作日志前必须先导出。
4. 调整数据保留策略前必须确认备份策略有效。
5. 发布前必须先停服务再替换 jar。
