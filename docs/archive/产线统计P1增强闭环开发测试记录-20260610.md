# 产线统计 P1 增强闭环开发测试记录（2026-06-10）

## 本轮交付功能

1. 大时间范围查询自动走日聚合表
   - 阈值：查询日期跨度达到 3 天及以上时，自动使用 `agg_quality_day` / `agg_defect_type_day`。
   - 返回字段：`aggregationLevel=DAY|30M`、`aggregationMessage`、`aggregationThresholdDays`。
   - 若日聚合表当前范围未构建，查询前同步补齐一次，避免大范围查询返回空数据。

2. 看板模板复制 / 另存为
   - 新增后端接口：`POST /api/v1/analytics/dashboards/{id}/copy`。
   - 前端在产线统计页顶部和画布操作区增加“复制模板”“另存为”。
   - 复制时同步复制原看板下所有启用图表配置。

3. 图表导出
   - 新增后端接口：`GET /api/v1/analytics/widgets/{id}/export`。
   - 导出格式：`.xlsx`，支持 KPI、趋势、缺陷排行、工位排行、相机排行、透视表、映射异常明细。
   - 前端每个图表卡片增加“导出图片”“导出Excel”。ECharts 图表支持 PNG 导出；表格/KPI 首期提示使用 Excel 导出。

4. 聚合任务持久化到数据库
   - 新增表：`analytics_aggregation_job`。
   - `POST /aggregation/daily/run` 写入任务记录，异步完成后更新 `SUCCESS/FAILED`、行数和完成时间。
   - `GET /aggregation/jobs/recent` 从数据库读取，服务重启后仍可查询历史任务。

5. 图表配置弹窗实时预览
   - 新增/编辑图表弹窗增加“实时预览”。
   - 预览使用当前全局筛选数据，保存后按图表自身配置生效。
