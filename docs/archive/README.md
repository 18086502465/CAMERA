## 五、读这几类文档的三条规矩

1. **先看日期再看结论。** 同一天的 v1/v2/v3 是迭代关系，不是并列选项 —— 永远只信编号最大且未被标注推翻的那份。
2. **数字一律回代码/现场核。** 这几轮里出现过 5 次数字自纠：文件数 188→662、库体量 2.6GB→43MB、
   日增容量 780MB→67MB、binlog「未开启」→实为开启、跨域依赖 5 处→13 处。凭记忆写的数字不可信。
3. **被推翻的结论不要删，要标注。** 保留推翻过程说明当时的证据错在哪 —— 这是这一层唯一不可替代的价值。
