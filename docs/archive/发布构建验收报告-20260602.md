## 6. 注意事项

1. 安装包已内置 JRE，目标电脑不需要单独安装 Java。
2. 目标电脑仍需安装 MySQL 8.0，并导入 `sql\wms-new.sql`。
3. MySQL `3306` 默认建议仅本机访问，不建议对外开放。
4. 应用页面和相机上报统一使用 `TCP 8091`。
5. 如需重新打包，执行：

```powershell
cd D:\45344\0004-软件源码
.\build-release.ps1 -BundleJre
```
