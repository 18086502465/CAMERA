# 部署操作说明

## 1. 部署目标

目标是在一台 Windows 电脑上安装并运行相机检测系统：

```text
Windows 电脑
├─ MySQL 8.0
│  └─ 数据库：wms-new
│
└─ 相机检测系统 Windows 服务
   ├─ Spring Boot 后端
   ├─ Vue 前端静态页面
   ├─ 图片上传目录
   ├─ 日志目录
   ├─ 外部配置 application.yml
   └─ 内置 JRE
```

## 2. 端口规划

| 端口 | 用途 | 开放建议 |
|---:|---|---|
| 8091 | 页面访问 + 相机接口上报 | 对相机和局域网浏览器开放。 |
| 3306 | MySQL | 默认仅本机使用，不建议对外开放。 |

## 3. 安装包位置

最终安装程序：

```text
D:\45344\0004-软件源码\dist-release\installer\CameraDetectionSystem-Setup-1.0.0.exe
```

安装包已内置 JRE，目标电脑不需要单独安装 Java。

## 4. 目标电脑前置条件

1. Windows 电脑，建议 64 位。
2. 安装 MySQL 8.0。
3. 准备数据库 `wms-new`。
4. 准备安装包 `CameraDetectionSystem-Setup-1.0.0.exe`。

## 5. 数据库初始化

创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS `wms-new`
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_general_ci;
```

导入 SQL：

```powershell
mysql -h127.0.0.1 -P3306 -uroot -p wms-new < "C:\Program Files\CameraDetectionSystem\sql\wms-new.sql"
```

如果安装目录不是默认目录，请替换 SQL 路径。

## 6. 安装系统

以管理员身份运行：

```text
CameraDetectionSystem-Setup-1.0.0.exe
```

默认安装目录：

```text
C:\Program Files\CameraDetectionSystem
```

安装完成后会自动执行：

```powershell
scripts\install-service.ps1
```

并创建 Windows 服务：

```text
ServiceName: CameraDetectionSystem
DisplayName: Camera Detection System
```

## 7. 配置文件

配置文件路径：

```text
C:\Program Files\CameraDetectionSystem\config\application.yml
```

重点配置：

```yaml
server:
  port: 8091

spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/wms-new?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: ${MYSQL_PASSWORD}

app:
  home: ${APP_HOME:./}
  upload:
    image-dir: ${app.home}/data/uploads/images

defect-image:
  upload:
    dir: ${app.home}/data/uploads/defect-images/

logging:
  file:
    name: ${app.home}/logs/camera-detection-system.log
```

Windows 服务启动时会通过 `-Dapp.home=<安装目录>` 指定运行根目录。

## 8. 服务管理

进入安装目录：

```powershell
cd "C:\Program Files\CameraDetectionSystem"
```

安装服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-service.ps1
```

```powershell

```

```powershell

```

```powershell

```

控制台调试：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-console.ps1
```

## 10. 相机接口验证

### 10.1 心跳

```http
POST http://localhost:8091/api/v1/camera/status/heartbeat
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
Content-Type: application/json
```

### 10.2 检测上报

```http
POST http://localhost:8091/api/v1/camera/inspection/batch-upload
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
Content-Type: application/json
```

### 10.3 缺陷图片上传

```http
POST http://localhost:8091/api/v1/defect-images/upload
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
Content-Type: multipart/form-data
```

表单：

- `metadata`：JSON 字符串。
- `files`：图片数组。
- 或多个同名 `file` 字段，系统已兼容。

## 14. 常见问题

### 14.1 页面打不开

检查：

1. 服务是否启动。
2. 8091 是否被占用。
3. `logs/service-err.log` 是否有启动失败。
4. `config/application.yml` 端口是否改动。

### 14.2 数据库连接失败

检查：

1. MySQL 是否启动。
2. `wms-new` 是否已创建并导入 SQL。
3. 用户名密码是否正确。
4. MySQL 是否允许本机连接。

### 14.3 上传成功但页面不显示

检查：

1. 顶部工厂/产线/工位筛选是否过滤掉当前相机。
2. `metadata.images[].fileName` 是否与文件名完全一致。
3. `data/uploads/defect-images` 是否有实际文件。
4. `GET /api/v1/defect-images/recent?cameraId=<cameraId>` 是否能查到数据。
