## 四、优化点清单（按优先级）

### O-1 【高】设备重传风暴治理（源头）
- **证据**：DAN 昨日 245 次 EOF + 4,336 次幂等跳过；今日 17 点 1,304 次重传。
- **动作**：① 现场排查 DAN 相机网络/采集端（优先，属于设备侧）；② 服务端对幂等跳过的图片改为**DEBUG 级别或聚合计数日志**（当前每张一条 INFO，1,300+/小时污染日志与 I/O）；③ 考虑对同一 `(cameraId, fileName)` 短窗口重复上报返回轻量 204 而非完整查重流程。
- **收益**：日志量降 90%+、Tomcat 线程与 GC 压力下降、磁盘 I/O 下降。
- **风险**：低（仅日志级别与响应形态）；需保留可观测性（每分钟汇总一条 WARN/INFO）。

### O-2 【高】line-summary 预热缓存命中率
- **证据**：浏览器冷查 1.6s×2，curl 同参 5ms；预热 `fixedDelay=45s`，键按分钟归一化，前端 `endTime` 固定整分钟 → 分钟切换瞬间 miss。
- **动作**：① 预热频率 45s → 20–30s（覆盖分钟切换窗口）；② 预热失败/耗时写调试日志便于观测命中率；③ 或在分钟切换时立即补一次预热（监听时钟事件）。
- **收益**：产线统计首屏 2.9s → ~1.2s（两个 1.6s 冷查变 5ms）。
- **风险**：低（预热是增强，失败只 WARN）；代价是每 30s 多一次 1.3s 后台查询。

### O-3 【中】/api/cascade/all 重复请求去重
- **证据**：日报页 API 8 次中 `/api/cascade/all` 出现 2 次（Layout 顶层 + DailyReportView 各自调用）。
- **动作**：把 `getCascadeAll()` 纳入 `analytics.js getDedup()` 同款 in-flight 复用（跨模块共享 Promise，5min TTL）；或 Layout 通过 `provide/inject` 把已加载的级联树下发给子页。
- **收益**：日报页少 1 次请求，级联数据一致。
- **风险**：低；注意缓存失效（用户点「刷新配置」时须清缓存）。

### O-4 【中】JVM 内存占用偏高
- **证据**：RSS 5.3G（Xmx 3,986m），GC 频繁（Eden 1,836M→0，Heap 3.76G→122M）。
- **动作**：① 分析 GC 日志确认 Young GC 频率与耗时分布；② 若重传导致的短生命周期对象为主，O-1 落地后自然下降；③ 再评估 Xmx 下调（→3g）与 `-XX:G1ReservePercent` 调整。
- **收益**：内存占用下降、GC 暂停缩短。
- **风险**：中（需先观测，勿直接改 Xmx）。

### O-5 【中】日报月历冷查 1.07s
- **证据**：`/api/daily-report/calendar?month=2026-11` 浏览器实测 1,066ms；项目已有 30s TtlCache 但首访 miss。
- **动作**：预热当前月份 calendar（与 O-2 同批次，启动时 + 每小时）；或对月历做「最近 3 个月」滚动预热。
- **收益**：日报首屏 2.0s → ~1.0s。
- **风险**：低。

### O-6 【低】观测能力补齐
- **证据**：`slow_query_log=OFF`、`long_query_time=10s`；GC 日志 6.3M/轮但无聚合告警；当前 0 慢查询不等于无慢 SQL（阈值太高）。
- **动作**：开慢查询日志、`long_query_time=1s`（先观察 1 周）；把 GC Pause 99 分位接入现有服务器监控页。
- **收益**：后续优化有数据支撑，避免再靠猜测。
- **风险**：低（慢日志磁盘占用可控，/var 19%）。

### O-7 【低】DBN 设备配置遗留
- **证据**：WARN「设备未在系统配置中维护: DBN」51 次 + 「缺陷图片来自未配置相机」20 次 + 未配置令牌 134 次。
- **动作**：现场确认 DBN 是什么设备；若在用则在系统配置补档案/令牌，若废弃则核查其上报来源是否误配。
- **收益**：日志噪音清零、避免无主数据入库。
- **风险**：低（配置侧操作）。

### O-8 【低】配置侧 `camera.token.strict`
- **证据**：DAN/DBN 均「未配置设备令牌，心跳兼容放行」410 次 WARN。
- **动作**：为相机配置令牌后开启 `camera.token.strict=true`（**注意**：须先确认所有在用相机都已配令牌，否则会拒绝合法心跳）。
- **收益**：消除未授权设备随意上报的残余风险（与 8091 不对外网暴露形成双保险）。
- **风险**：中（配置漏项会导致心跳被拒），须分批灰度。
