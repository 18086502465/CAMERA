# P0 安装部署验收方案（2026-06-07）

## 1. 目标

验证 `产线缺陷在线AI检测系统` 在一台全新 Windows 电脑上的最小交付链路：

1. 安装 MySQL 8.0。
2. 一键初始化数据库 `wms-new`。
3. 安装系统安装包。
4. Windows 服务可安装、启动、停止、卸载。
5. 页面可访问，相机接口可上报。

| 参数 | 默认值 |
|---|---|

### 4.2 使用方式

方式一：开始菜单点击：

```text
产线缺陷在线AI检测系统 > 初始化数据库
```

方式二：命令行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "{安装目录}\scripts\init-database.ps1" -Yes
```

自定义密码：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "{安装目录}\scripts\init-database.ps1" -Password "你的MySQL密码" -Yes
```

> 注意：当前 SQL 包含 `DROP TABLE / CREATE TABLE`，会重建系统表并写入初始数据。新电脑首次安装可直接执行；已有生产数据环境必须先备份。

## 7. 全新 Windows 验收步骤

1. 安装 MySQL 8.0。
2. 确认 MySQL 服务启动。
3. 运行安装包。
4. 安装时选择：
   - 软件安装目录。
   - 工作路径，用于日志、图片、运行数据。
5. 执行“初始化数据库”。
6. 执行“启动系统服务”。
7. 执行“安装自检”。
8. 浏览器访问：`http://localhost:8091`。
9. Postman 调用：
   - `/api/v1/camera/status/heartbeat`
   - `/api/v1/camera/inspection/batch-upload`
   - `/api/v1/defect-images/upload`
10. 验证页面数据展示。

## 8. 验收通过标准

- 不需要单独安装 Java，系统服务可启动。
- MySQL 初始化脚本可一键创建并导入 `wms-new`。
- 服务可启动、停止、查看状态、卸载。
- 页面访问正常。
- 相机状态接口可写入数据。
- 缺陷图片上传最多 100 张，超过 100 张快速失败。

## 9. 风险与注意事项

- 数据库初始化脚本会重建表，生产环境执行前必须备份。
- TCP 3306 默认只建议本机使用，不建议对外开放。
- TCP 8091 用于页面访问和相机接口上报。
- 若 MySQL 密码不是默认值，需要执行初始化脚本时传入 `-Password`。
