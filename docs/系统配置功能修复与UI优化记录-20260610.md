## 1. 本次处理目标

## 2. 修复内容

### 2.1 前端系统配置页

文件：`D:\45344\0004-软件源码\frontend\src\views\system\ConfigView.vue`

主要调整：

- 新增顶部专业配置工作台 Hero 区：展示系统配置说明、工厂/产线/工位/相机数量和导入操作。
- 左侧配置导航改为完整配置对象导航，包含：
  - 配置总览
  - 产线管理
  - 工位管理
  - 相机管理
  - 产品管理
  - 缺陷类型
  - 相机缺陷映射
  - 映射异常
  - 用户管理
  - 操作记录
- 层级关系模块默认收起，不再默认展开整棵树。
- 层级关系作为辅助筛选模块，展开后可按工厂 → 产线 → 工位 → 相机定位。
- 新增“清除筛选”能力，避免层级筛选影响用户判断。
- 修复“新增相机”表单：
  - 支持先选产线再选工位。
  - 从工位层级进入时自动锁定产线和工位。
- 修复新增按钮逻辑：
  - 在“配置总览”新增工厂。
  - 在“产线管理”新增产线。
  - 在“工位管理”新增工位。
  - 在“相机管理”新增相机。
  - 不再因层级树节点导致新增对象错乱。
- 优化卡片、导航、表格、按钮、层级区域样式。

### 2.2 后端配置操作修复

文件：

- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\controller\CameraDashboardController.java`
- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\controller\DimFactoryController.java`
- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\controller\DimProductionLineController.java`

主要调整：

- 修复工厂删除、产线删除返回成功但数据未真正逻辑删除的问题。
- 相机新增 / 修改时同步维护最终模型表 `dim_camera`，保证：
  - 相机管理页维护后的相机可以用于缺陷映射配置。
  - `/api/v1/camera/inspection/batch-upload` 可按最终模型识别新相机。
- 相机保存时校验：
  - 相机名称必填。
  - 设备编号必填且唯一。
  - 必须选择工位。
  - 产线与工位归属必须一致。
- 相机删除时同步将 `dim_camera` 标记为删除 / 停用。
