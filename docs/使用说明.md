# 使用说明

> 面向产线管理员与操作员 · 更新：2026-11-07
> 浏览器访问 `http://<服务器IP>:8091/`（Chrome / Edge）

---

## 1. 登录与账号

- 默认账号：`admin`（管理员）。首次登录后请由管理员在服务器上改密。
- 登录态失效（token 过期）时会自动跳回登录页并提示，登录后**自动返回原页面**。
- 权限不足的提示为「没有访问权限」且**不会**跳出当前页 —— 这是设计行为
  （401=未登录跳登录；403=权限不足仅提示）。

## 2. 页面导览

### 相机状态（首页）
- 左侧树：工厂 → 产线 → 工位 → 相机，徽标带单位（`2厂/1线/14位/1机`）
- 右侧卡片：相机在线状态、最近心跳、识别计数（总数/OK/异常）
- 心跳约每 5 秒一次，页面轮询自动刷新

### 图像记录
- 一行一个相机（含图片总数与最近缩略图），点击展开该相机的历史图片
- 支持按相机/产线/时间范围/关键字筛选；分页加载
- 良率列显示「—」表示该通道无良品样本（设计行为，不代表 0%）

### 产线统计
- 工厂质量看板（厂长视角）：总览、缺陷帕累托、严重度分布、工位/相机排名、趋势
- 支持时间范围与产品/班次维度筛选；看板可配置（系统配置 → 看板管理）

### 服务器监控
- CPU / 内存 / 磁盘 / JVM 指标实时展示

### 系统配置（仅管理员）
| 标签 | 说明 |
|---|---|
| 组织档案 | 工厂 / 产线 / 工位 的增删改；**删除带依赖保护**（有下属数据时给出明细并拒绝） |
| 相机档案 | 相机与工位绑定（`camera_code` 为唯一标识）；换绑自动联动状态与缺陷映射 |
| 缺陷类型 / 产品 / 品牌 | 检测业务字典 |
| 看板管理 | 看板与组件配置 |
| 系统设置 | 全局参数 |
| 配置导入 | Excel 批量导入（提供模板下载）；导入后可导出结果核对 |

## 3. 常见操作

| 操作 | 说明 |
|---|---|
| 删除工厂/产线/工位 | 有下属数据会被拦截并列出依赖明细；工位删除会**自动停用**绑定相机（不会留悬空绑定） |
| 相机换工位 | 自动同步状态快照与缺陷检测映射，无需手工改配置 |
| 页面提示「系统已更新」 | 部署了新版本，点击刷新即可（旧页面也会自动刷新一次，防止点击无反应） |
| 忘记密码 | 联系管理员在服务器执行 `reset-password.sh` |

## 4. 数据口径须知

- 图片记录由设备上传产生（`defect_image_file`）。**在线可查 31 天**，更早的记录按月搬到归档表
  （`defect_image_*_hist_YYYYMM`），页面按时间范围自动路由，最多可查 **730 天**；
  磁盘上的原图同样保留 730 天，`/file/**` 照常回放
- 查询跨度涉及归档月份时页面会慢一些（要跨表 UNION），属正常表现
- 相机身份以 **camera_code**（设备编号）为准；`camera_name` 可能重名，不作为唯一标识
- 统计报表读取实时图片表（`defect_image_*`）与聚合表双通道，响应中带 `dataSource` 标注
