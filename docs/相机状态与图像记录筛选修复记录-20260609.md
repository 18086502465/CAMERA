# 相机状态与图像记录筛选修复记录

更新时间：2026-06-09

## 修复范围

本次修复覆盖：

- 顶部工厂 / 产线 / 工位筛选与相机状态页联动。
- 顶部工厂 / 产线 / 工位筛选与图像记录页联动。
- 图像记录页历史图片文件无法展示的问题。
- 后端相机列表接口缺少工厂 / 产线展示字段的问题。
- 缺陷图片 recent 接口在选择工厂时仍返回未配置相机图片的问题。

## 后端修复

### 1. 相机列表接口补充层级字段

接口：

- `GET /api/cameras`

补充返回：

- `factoryId`
- `lineName`
- `lineCode`
- `stationName`
- `stationCode`
- `stationLabel`

相关文件：

- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\entity\CameraStatus.java`
- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\controller\CameraDashboardController.java`

### 2. 缺陷图片 recent 接口工厂筛选修复

接口：

- `GET /api/v1/defect-images/recent`

修复前：

- 选择 `factoryId` 时，未配置工厂的历史图片也会返回。

修复后：

- 选择 `factoryId` 时，仅返回已映射到该工厂的图片。
- 全部工厂时，仍保留未配置相机的历史图片，便于追溯。

相关文件：

- `D:\45344\0004-软件源码\fact-product\src\main\java\com\wms\service\impl\DefectImageServiceImpl.java`

### 3. 图片文件读取增加历史路径兼容

接口：

- `GET /api/v1/defect-images/file/**`

修复前：

- 只按当前配置的上传根目录读取文件。
- 安装目录 / 工作目录切换后，历史图片在数据库中有 `image_path`，但 URL 访问 404。

修复后：

- 优先按当前上传目录读取。
- 当前目录找不到时，根据 `defect_image_file.image_url` 回查数据库中的 `image_path`。
- 可兼容安装目录下旧图片路径和当前 runtime 图片路径。

验证：

- `GET /api/v1/defect-images/file/20260531/cv6-001/233012123_f3ddf586.jpg` 返回 `200 image/jpeg`。
