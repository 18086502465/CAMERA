# 相机检测系统部署说明和验收清单

## 1. 部署目标

在一台 Windows 电脑上安装：

```text
Windows 电脑
├─ MySQL 8.0
│  └─ 数据库：wms-new
│
└─ 相机检测系统 Windows 服务
   ├─ Spring Boot 后端
   ├─ Vue 前端静态页面
   ├─ 图片上传目录
   ├─ 日志目录
   └─ 外部配置 application.yml
```

端口策略：

- `TCP 8091`：页面访问和相机接口上报统一入口。
- `TCP 3306`：仅本机 MySQL 使用，默认不建议对外开放。

## 3. 一键构建

在 PowerShell 中执行：

```powershell
cd D:\45344\0004-软件源码
.\build-release.ps1
```

如果目标电脑不安装 Java，构建时可把本机 `JAVA_HOME` 下的 JRE 一起打入发布包：

```powershell
cd D:\45344\0004-软件源码
.\build-release.ps1 -BundleJre
```

说明：

1. 脚本会先执行 Vue 构建。
2. 将 `frontend/dist` 复制到 Spring Boot `src/main/resources/static`。
3. 执行 Maven 打包，得到内置前端页面的 Spring Boot jar。
4. 编译 Windows 服务包装器 `CameraDetectionService.exe`。
5. 生成发布目录。
6. 如果检测到 Inno Setup，会继续生成安装 exe；否则只生成发布目录。

## 4. 数据库安装

### 4.1 安装 MySQL 8.0

建议：

- MySQL 服务仅监听本机或仅允许本机访问。
- 数据库名：`wms-new`
- 用户：`root`
- 密码：以现场配置为准，默认模板为 `CCshenda889`。

### 4.2 初始化数据库

进入 MySQL 客户端后执行：

```sql
CREATE DATABASE IF NOT EXISTS `wms-new`
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_general_ci;
```

导入发布包中的 SQL：

```powershell
mysql -h127.0.0.1 -P3306 -uroot -p wms-new < "C:\Program Files\CameraDetectionSystem\sql\wms-new.sql"
```

## 5. 应用配置

配置文件：

```text
C:\Program Files\CameraDetectionSystem\config\application.yml
```

重点配置：

```yaml
server:
  port: 8091

spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/wms-new?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: CCshenda889

app:
  home: ${APP_HOME:./}
  upload:
    image-dir: ${app.home}/data/uploads/images

defect-image:
  upload:
    dir: ${app.home}/data/uploads/defect-images/

logging:
  file:
    name: ${app.home}/logs/camera-detection-system.log
```

Windows 服务启动时会通过 `-Dapp.home=<安装目录>` 指定运行根目录，所以默认图片和日志会写入安装目录下：

- `data/uploads/defect-images`
- `data/uploads/images`
- `logs`

如现场要求把数据放到其他磁盘，可修改：

```yaml
app:
  home: D:/CameraDetectionSystemRuntime
```

## 8. 相机接口验收

### 8.1 心跳接口

```http
POST http://localhost:8091/api/v1/camera/status/heartbeat
Content-Type: application/json
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
```

### 8.2 检测批量上报

```http
POST http://localhost:8091/api/v1/camera/inspection/batch-upload
Content-Type: application/json
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
```

### 8.3 缺陷图片上传

```http
POST http://localhost:8091/api/v1/defect-images/upload
Content-Type: multipart/form-data
Authorization: Bearer <device-token>
X-Device-Id: cv6-001
```

表单字段：

- `metadata`：JSON 字符串。
- `files`：图片数组。
- 兼容 Postman 中多个同名 `file` 字段。

上传成功后：

1. 图片文件进入 `data/uploads/defect-images`。
2. 数据写入 `defect_image_batch`、`defect_image_file`、`defect_image_box`。
3. 页面 `图像记录` 和 `相机状态` 可查询展示。

## 9. 防火墙建议

- 开放入站 `TCP 8091`，供浏览器和相机设备访问。
- 不建议对外开放 `TCP 3306`。
- MySQL 建议仅本机访问：应用通过 `127.0.0.1:3306` 连接。

## 11. 常见问题

### 页面能打开，但接口报数据库连接失败

检查：

1. MySQL 服务是否启动。
2. `config/application.yml` 中数据库地址、库名、用户名、密码是否正确。
3. SQL 是否已导入 `wms-new`。

### 服务启动失败

检查：

1. `logs/service-wrapper.log`
2. `logs/service-err.log`
3. 是否安装 Java 8+，或发布包是否带 `jre` 目录。
4. `app/time-bucket-demo.jar` 是否存在。
5. `config/application.yml` 是否存在。

### 上传图片成功但页面不显示

检查：

1. 页面顶部工厂/产线/工位筛选是否过滤掉当前相机。
2. `metadata.images[].fileName` 是否与 multipart 文件名一致。
3. `data/uploads/defect-images` 是否有实际文件。
4. `GET /api/v1/defect-images/recent?cameraId=<cameraId>` 是否能查到数据。
