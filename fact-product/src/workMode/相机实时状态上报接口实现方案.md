## 一、需求分析

### 1.1 接口概述

| 项目 | 内容 |
|------|------|
| 接口路径 | `/api/v1/camera/status/heartbeat` |
| 请求方式 | POST |
| 数据格式 | `application/json; charset=utf-8` |
| 幂等性 | 基于 `cameraName + timestamp` 更新最新状态 |
| 超时时间 | 建议设置 5 秒（轻量级数据） |
| 上报频率 | 每 5 秒高频上报 |

### 1.2 接口核心功能

1. **实时状态监控**：接收相机每 5 秒上报的运行状态
2. **计数数据收集**：收集累计识别数、OK数、NG数
3. **资源监控**：收集CPU、内存、温度等系统资源信息
4. **异常告警**：当状态为故障(2)时触发告警
5. **离线判定**：超过 15 秒未上报则标记为离线
6. **配置下发**：可向下行配置版本号，提示相机更新配置

### 1.3 请求参数

#### 1.3.1 请求头 (Header)

| 参数 | 必填 | 说明 |
|------|------|------|
| Content-Type | 是 | `application/json` |
| Authorization | 是 | `Bearer {token}` (认证令牌) |
| X-Device-Id | 是 | 相机设备编号 |

#### 1.3.2 请求体 (Body)

```json
{
  "cameraName": "正面检测",
  "productName": "008 小护-K8",
  "timestamp": "2025-12-30 16:34:05",
  "cameraStatus": 1,
  "recognizeCount": 1500,
  "correctCount": 1450,
  "abnormalCount": 50,
  "cpuUsage": 45.5,
  "memoryUsage": 60.2,
  "temperature": 35.5,
  "errorMessage": ""
}
```

#### 1.3.3 字段说明

| 模块 | JSON 字段 | 类型 | 说明 | 枚举/格式 |
|------|-----------|------|------|-----------|
| 基础信息 | cameraName | String | 相机名称 | 例：正面检测 |
| 基础信息 | productName | String | 当前生产产品 | 例：008 小护-K8 |
| 基础信息 | timestamp | String | 上报时间 | `yyyy-MM-dd HH:mm:ss` |
| 状态信息 | cameraStatus | Integer | 相机运行状态 | 0:停止, 1:运行, 2:故障, 3:待机 |
| 计数信息 | recognizeCount | Integer | 识别总数 (累计) | 当前会话累计识别数量 |
| 计数信息 | correctCount | Integer | 识别正确数 (累计) | 当前会话累计 OK 数量 |
| 计数信息 | abnormalCount | Integer | 识别异常数 (累计) | 当前会话累计 NG 数量 |
| 资源监控 | cpuUsage | Double | CPU 使用率 | 百分比 (0-100) |
| 资源监控 | memoryUsage | Double | 内存使用率 | 百分比 (0-100) |
| 资源监控 | temperature | Double | 设备温度 | 摄氏度 (℃) |
| 异常信息 | errorMessage | String | 故障错误信息 | 状态为 2 时填写 |

### 1.4 响应格式

#### 1.4.1 成功响应 (HTTP 200)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "serverTime": "2025-12-30 16:34:05",
    "nextInterval": 5000,
    "configVersion": "v1.2.0"
  }
}
```

#### 1.4.2 失败响应 (HTTP 4xx/5xx)

```json
{
  "code": 400,
  "message": "Invalid cameraStatus",
  "data": null
}
```

#### 1.4.3 状态码定义

| 代码 | 含义 | 处理建议 |
|------|------|----------|
| 200 | 成功 | 状态已更新 |
| 400 | 参数错误 | 检查状态枚举值 |
| 401 | 未授权 | 检查 Token |
| 403 | 设备禁用 | 相机未被平台授权 |
| 500 | 服务器错误 | 联系运维 |

## 四、Redis 缓存设计

### 4.1 缓存结构设计

| Key 格式 | 类型 | TTL | 说明 |
|----------|------|-----|------|
| `camera:status:{cameraName}` | String | 15秒 | 相机实时状态 |
| `camera:config:{cameraName}` | String | 永久 | 相机配置版本 |

### 4.2 缓存数据格式

```json
// Key: camera:status:正面检测
{
  "cameraName": "正面检测",
  "productName": "008 小护-K8",
  "cameraStatus": 1,
  "recognizeCount": 1500,
  "correctCount": 1450,
  "abnormalCount": 50,
  "cpuUsage": 45.5,
  "memoryUsage": 60.2,
  "temperature": 35.5,
  "errorMessage": "",
  "lastHeartbeatTime": "2025-12-30 16:34:05",
  "expireAt": 1703925305
}
```

### 4.3 离线判定逻辑

```
定时任务每5秒执行：
1. 扫描所有 camera:status:* 的Key
2. 检查 TTL 是否 < 0（已过期）
3. 若过期，将数据库中的 camera_status 更新为 9（离线）
4. 删除或标记该缓存
```

#### 5.2.4 Controller 类 - CameraStatusController

```java
package com.wms.controller;

import com.wms.dto.CameraHeartbeatDTO;
import com.wms.dto.CameraHeartbeatResponseDTO;
import com.wms.entity.CameraRealtimeStatus;
import com.wms.service.ICameraRealtimeStatusService;
import com.wms.vo.ResultVO;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.*;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.concurrent.TimeUnit;

/**
 * 相机实时状态Controller
 */
@RestController
@RequestMapping("/api/v1/camera/status")
@Slf4j
public class CameraStatusController {
    
    @Autowired
    private ICameraRealtimeStatusService cameraRealtimeStatusService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String CAMERA_STATUS_KEY_PREFIX = "camera:status:";
    private static final int CACHE_TTL_SECONDS = 15;
    private static final DateTimeFormatter DATE_TIME_FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    /**
     * 相机心跳上报接口
     */
    @PostMapping("/heartbeat")
    public ResultVO<CameraHeartbeatResponseDTO> heartbeat(
            @RequestHeader("Authorization") String authorization,
            @RequestHeader("X-Device-Id") String deviceId,
            @Validated @RequestBody CameraHeartbeatDTO heartbeatDTO) {
        
        try {
            // 1. 认证校验
            if (!AuthUtils.validateToken(authorization)) {
                return ResultVO.fail("认证失败，无效的Token", null);
            }
            
            // 2. 参数校验
            if (!isValidCameraStatus(heartbeatDTO.getCameraStatus())) {
                return ResultVO.fail("无效的相机状态码：" + heartbeatDTO.getCameraStatus(), null);
            }
            
            // 3. 计数逻辑校验
            if (!validateCountLogic(heartbeatDTO)) {
                log.warn("相机 {} 计数逻辑异常", heartbeatDTO.getCameraName());
            }
            
            // 4. 构建响应
            CameraHeartbeatResponseDTO response = new CameraHeartbeatResponseDTO();
            response.setServerTime(LocalDateTime.now().format(DATE_TIME_FORMATTER));
            response.setNextInterval(5000); // 5秒
            response.setConfigVersion("v1.0.0");
            
            // 5. 更新Redis缓存
            updateRedisCache(heartbeatDTO);
            
            // 6. 更新数据库（异步或同步）
            updateDatabase(heartbeatDTO);
            
            // 7. 异常判断
            handleException(heartbeatDTO);
            
            return ResultVO.success(response, "success");
            
        } catch (Exception e) {
            log.error("相机心跳处理异常", e);
            return ResultVO.fail("服务器内部错误：" + e.getMessage(), null);
        }
    }
    
    /**
     * 验证相机状态码
     */
    private boolean isValidCameraStatus(Integer status) {
        return status != null && (status == 0 || status == 1 || status == 2 || status == 3);
    }
    
    /**
     * 计数逻辑校验：recognizeCount ≈ correctCount + abnormalCount
     */
    private boolean validateCountLogic(CameraHeartbeatDTO dto) {
        if (dto.getRecognizeCount() == null || dto.getCorrectCount() == null || dto.getAbnormalCount() == null) {
            return true; // 允许为空
        }
        int sum = dto.getCorrectCount() + dto.getAbnormalCount();
        return Math.abs(dto.getRecognizeCount() - sum) <= 1; // 允许1以内误差
    }
    
    /**
     * 更新Redis缓存
     */
    private void updateRedisCache(CameraHeartbeatDTO dto) {
        String key = CAMERA_STATUS_KEY_PREFIX + dto.getCameraName();
        try {
            redisTemplate.opsForValue().set(key, dto, CACHE_TTL_SECONDS, TimeUnit.SECONDS);
        } catch (Exception e) {
            log.error("更新Redis缓存失败", e);
        }
    }
    
    /**
     * 更新数据库
     */
    private void updateDatabase(CameraHeartbeatDTO dto) {
        try {
            CameraRealtimeStatus status = new CameraRealtimeStatus();
            status.setCameraName(dto.getCameraName());
            status.setProductName(dto.getProductName());
            status.setCameraStatus(dto.getCameraStatus());
            status.setRecognizeCount(dto.getRecognizeCount());
            status.setCorrectCount(dto.getCorrectCount());
            status.setAbnormalCount(dto.getAbnormalCount());
            status.setCpuUsage(dto.getCpuUsage());
            status.setMemoryUsage(dto.getMemoryUsage());
            status.setTemperature(dto.getTemperature());
            status.setErrorMessage(dto.getErrorMessage());
            status.setLastHeartbeatTime(LocalDateTime.now());
            status.setServerTime(LocalDateTime.now());
            
            cameraRealtimeStatusService.saveOrUpdateByCameraName(status);
        } catch (Exception e) {
            log.error("更新数据库失败", e);
        }
    }
    
    /**
     * 异常处理
     */
    private void handleException(CameraHeartbeatDTO dto) {
        // 1. 状态==2 (故障) → 触发告警通知
        if (dto.getCameraStatus() == 2) {
            log.error("相机 {} 发生故障：{}", dto.getCameraName(), dto.getErrorMessage());
            // TODO: 发送告警通知
        }
        
        // 2. 资源过高 (CPU>90%) → 记录预警
        if (dto.getCpuUsage() != null && dto.getCpuUsage() > 90.0) {
            log.warn("相机 {} CPU使用率过高：{}%", dto.getCameraName(), dto.getCpuUsage());
        }
        
        // 3. 温度异常 (>60℃) → 记录预警
        if (dto.getTemperature() != null && dto.getTemperature() > 60.0) {
            log.warn("相机 {} 温度异常：{}℃", dto.getCameraName(), dto.getTemperature());
        }
    }
    
    /**
     * 获取相机实时状态
     */
    @GetMapping("/{cameraName}")
    public ResultVO<CameraRealtimeStatus> getCameraStatus(@PathVariable String cameraName) {
        try {
            CameraRealtimeStatus status = cameraRealtimeStatusService.getByCameraName(cameraName);
            return ResultVO.success(status, "查询成功");
        } catch (Exception e) {
            log.error("查询相机状态异常", e);
            return ResultVO.fail("查询失败：" + e.getMessage(), null);
        }
    }
}
```

#### 5.2.8 定时任务 - CameraOfflineTask

```java
package com.wms.task;

import com.wms.entity.CameraRealtimeStatus;
import com.wms.service.ICameraRealtimeStatusService;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;
import java.time.LocalDateTime;
import java.time.temporal.ChronoUnit;
import java.util.List;
import java.util.Set;

/**
 * 相机离线判定定时任务
 */
@Component
@Slf4j
public class CameraOfflineTask {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private ICameraRealtimeStatusService cameraRealtimeStatusService;
    
    private static final String CAMERA_STATUS_KEY_PREFIX = "camera:status:";
    
    /**
     * 每5秒执行一次，判定相机是否离线
     */
    @Scheduled(fixedDelay = 5000)
    public void checkCameraOffline() {
        try {
            // 1. 获取所有相机状态Key
            Set<String> keys = redisTemplate.keys(CAMERA_STATUS_KEY_PREFIX + "*");
            
            if (keys == null || keys.isEmpty()) {
                return;
            }
            
            // 2. 检查每个Key的TTL
            for (String key : keys) {
                Long ttl = redisTemplate.getExpire(key);
                
                // TTL < 0 表示已过期
                if (ttl != null && ttl < 0) {
                    String cameraName = key.substring(CAMERA_STATUS_KEY_PREFIX.length());
                    log.warn("相机 {} 已离线（Redis Key过期）", cameraName);
                    
                    // 更新数据库状态为离线
                    cameraRealtimeStatusService.updateOfflineStatus(cameraName);
                    
                    // 删除过期Key
                    redisTemplate.delete(key);
                }
            }
            
        } catch (Exception e) {
            log.error("离线判定任务执行异常", e);
        }
    }
    
    /**
     * 备用方案：直接检查数据库中的最后心跳时间
     * 每30秒执行一次
     */
    @Scheduled(fixedDelay = 30000)
    public void checkCameraOfflineByDb() {
        try {
            // 查询所有相机
            List<CameraRealtimeStatus> allCameras = cameraRealtimeStatusService.list();
            
            LocalDateTime now = LocalDateTime.now();
            
            for (CameraRealtimeStatus camera : allCameras) {
                if (camera.getLastHeartbeatTime() == null) {
                    continue;
                }
                
                // 计算距离最后一次心跳的时间（秒）
                long secondsSinceLastHeartbeat = ChronoUnit.SECONDS.between(
                    camera.getLastHeartbeatTime(), now);
                
                // 超过15秒未上报，标记为离线
                if (secondsSinceLastHeartbeat > 15 && camera.getCameraStatus() != 9) {
                    log.warn("相机 {} 已离线（超过15秒未上报）", camera.getCameraName());
                    cameraRealtimeStatusService.updateOfflineStatus(camera.getCameraName());
                }
            }
            
        } catch (Exception e) {
            log.error("离线判定任务(DB)执行异常", e);
        }
    }
}
```

#### 5.2.9 认证工具类 - AuthUtils

```java
package com.wms.utils;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.SignatureAlgorithm;
import java.util.Date;

/**
 * 认证工具类（简单Token验证）
 */
public class AuthUtils {
    
    private static final String SECRET_KEY = "your-secret-key-here"; // 应从配置文件读取
    private static final long EXPIRATION_TIME = 86400000; // 24小时
    
    /**
     * 验证Token
     */
    public static boolean validateToken(String authHeader) {
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            return false;
        }
        
        String token = authHeader.substring(7);
        
        try {
            Claims claims = Jwts.parser()
                    .setSigningKey(SECRET_KEY)
                    .parseClaimsJws(token)
                    .getBody();
            
            // 检查是否过期
            Date expiration = claims.getExpiration();
            return expiration == null || expiration.after(new Date());
            
        } catch (Exception e) {
            return false;
        }
    }
    
    /**
     * 生成Token（用于测试）
     */
    public static String generateToken(String deviceId) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + EXPIRATION_TIME);
        
        return Jwts.builder()
                .setSubject(deviceId)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(SignatureAlgorithm.HS512, SECRET_KEY)
                .compact();
    }
}
```

## 十、风险与建议

### 10.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Redis单点故障 | 实时状态丢失 | 配置Redis Sentinel或Cluster |
| 数据库写入瓶颈 | 接口响应慢 | 改为异步写入，批量提交 |
| Token泄露 | 安全问题 | 使用HTTPS，定期更换密钥 |

### 10.2 业务风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 相机时间不同步 | 数据混乱 | 使用服务器时间，忽略相机时间 |
| 网络延迟 | 离线误判 | 适当增加阈值（15秒→30秒） |
| 计数器重置 | 数据异常 | 支持resetFlag字段 |

### 10.3 优化建议

1. **异步处理**：心跳接口快速返回，数据库写入异步化
2. **批量处理**：累积多条记录后批量写入数据库
3. **降级策略**：Redis故障时，直接操作数据库
4. **监控告警**：接入Prometheus + Grafana
5. **链路追踪**：接入SkyWalking
