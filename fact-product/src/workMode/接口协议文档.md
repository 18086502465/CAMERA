# FACT-PRODUCT 接口协议文档

> **版本**: v1.0  
> **日期**: 2026-05-16  
> **说明**: 本文档适用于设备层接入开发，描述 fact-product 服务提供的所有 HTTP 接口。

---

## 一、服务概览

| 项目 | 说明 |
|------|------|
| 服务名称 | fact-product |
| 服务端口 | 8080 |
| 基地址 | `http://{host}:8080` |
| 协议类型 | HTTP/RESTful |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 文件上传限制 | 单文件最大 200MB，总请求最大 500MB |

---

## 二、通用返回格式

所有接口返回统一包装在 `ResultVO<T>` 中：

```json
{
  "code": 0,
  "message": "操作成功",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码：0-成功，1-失败 |
| message | String | 提示信息 |
| data | T | 业务数据 |

### 3.3 时间分桶维度接口

**Base Path**: `/DimTimeBucket30min`

#### 3.3.1 新增时间桶

- **接口地址**: `POST /DimTimeBucket30min`
- **Content-Type**: `application/json`
- **请求体**:

```json
{
  "fullDate": "2024-01-01",
  "hour": 8,
  "minuteGroup": "00",
  "startTime": "2024-01-01T08:00:00",
  "endTime": "2024-01-01T08:30:00"
}
```

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fullDate | LocalDate | 是 | 日期，格式 yyyy-MM-dd |
| hour | Byte | 是 | 小时（0-23） |
| minuteGroup | String | 是 | 分钟分组（00 或 30） |
| startTime | LocalDateTime | 是 | 该30分钟段起始时间 |
| endTime | LocalDateTime | 是 | 该30分钟段结束时间 |

- **响应**: `ResponseEntity<Boolean>`

---

#### 3.3.2 更新时间桶

- **接口地址**: `PUT /DimTimeBucket30min`
- **Content-Type**: `application/json`
- **请求体**: 同 3.3.1（需包含 `bucketId` 字段）

---

- **路径参数**:

## 五、设备层接入指南

### 5.1 数据上报流程

1. 设备层每 **2秒** 采集一次检测数据
2. 将采集数据写入 Excel 文件（格式见 3.1.1）
3. 调用 `POST /api/detection-history/import-excel-V2` 上传文件
4. 服务端解析 Excel 并进行增量计算后入库

### 5.2 注意事项

| 事项 | 说明 |
|------|------|
| 文件大小 | 单文件最大 200MB，总请求最大 500MB |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 累计值处理 | `totalCount`、`okCount`、`ngCount` 需上报累计值，服务端计算增量 |
| 清零处理 | 当设备重启或换线时，`recordType` 设为 1（清零记录） |
| 异常上报 | 有异常时填写 `exceptionType` 和 `exceptionItems` |

### 5.3 暂未实现的接口

以下 Controller 已定义但尚未实现，设备层暂不可用：
