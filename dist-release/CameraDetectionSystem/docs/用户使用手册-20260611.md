# 产线缺陷在线AI检测系统 - 用户使用手册

版本：2026-06-11  
适用地址：http://localhost:8091

## 1. 系统定位

本系统用于接收相机上报的运行心跳、检测统计和缺陷图片，面向工厂负责人、质量人员、设备维护人员提供相机状态、图像记录、产线统计和系统配置能力。

## 2. 登录与主界面

1. 打开浏览器访问 `http://localhost:8091`。
2. 输入管理员或普通用户账号登录。
3. 顶部固定主 Tab：
   - 相机状态：默认首页，查看相机实时状态、上传状态、资源指标。
   - 图像记录：按相机查看缺陷图片和缺陷框信息。
   - 产线统计：查看动态配置的质量统计图表。
4. 右上角显示当前登录用户，点击可进入个人中心或退出登录。

## 3. 相机状态

### 3.1 功能说明

- 查看相机总数、运行中数量、上传延迟/离线数量、故障/离线数量、近批次图片数和高危缺陷数。
- 支持搜索、状态筛选、异常优先排序。
- 表格默认按照数据库自增顺序展示。

### 3.2 状态口径

- 运行状态来自 `/api/v1/camera/status/heartbeat`。
- 上传状态来自缺陷图片上传或检测上报时间。
- 心跳和上传分别计算：
  - ≤30 秒：在线
  - 30~120 秒：延迟
  - >120 秒：离线

## 4. 图像记录

### 4.1 功能说明

- 按相机一行展示图片记录。
- 支持搜索图片文件名、相机名称、相机编号。
- 展开单个相机后查看图片分页。
- 点击图片可查看大图，并支持上一张/下一张切换。

### 4.2 上传失败排查

如图片不展示，请检查：

1. 请求接口是否为 `/api/v1/defect-images/upload`。
2. Header 是否包含设备 Token 和 `X-Device-Id`。
3. `metadata.images[].fileName` 是否和上传文件名完全一致。
4. 单批图片是否超过 100 张。
5. 文件是否为可解析图片格式。

## 5. 产线统计

### 5.1 功能说明

- 支持看板模板。
- 支持新增、编辑、删除图表。
- 支持图表尺寸调整、布局调整、独立筛选。
- 支持折线图、柱状图、堆叠图等 ECharts 图表。
- 大时间范围查询自动走日聚合数据。

### 5.2 图表操作

1. 点击“新增图表”。
2. 按引导选择统计维度、指标、图表类型。
3. 查看实时预览。
4. 保存时系统会进行二次确认。
5. 删除图表同样需要二次确认，确认后自动刷新看板。

## 6. 系统配置

进入方式：右上角“系统配置”。

### 6.1 配置总览

支持维护：

- 工厂
- 产线
- 工位
- 相机
- 产品
- 缺陷类型
- 相机缺陷映射
- 映射异常
- 用户
- 系统设置中心
- 操作记录

### 6.2 层级配置

工厂、产线、工位、相机是层级递进关系：

```text
工厂 -> 产线 -> 工位 -> 相机
```

层级关系默认收起，可按需展开。删除前系统会做依赖校验，存在下级配置或历史数据时禁止直接删除。

### 6.3 整体导入配置

支持全量导入和增量导入。

建议流程：

1. 下载模板。
2. 按模板填写工厂、产线、工位、相机。
3. 选择导入模式。
4. 上传 Excel。
5. 查看导入结果和失败行提示。

## 7. 系统设置中心

位置：系统配置 -> 系统设置中心。

可维护：

- 系统名称、站点名称。
- 相机在线/离线阈值。
- 缺陷图片单批上限。
- CPU、内存、温度告警阈值。
- 日聚合执行时间提示。
- 数据保留与清理策略。

保存设置时会弹出风险确认。上传目录、日志目录等安装级路径仍以外部 `application.yml` 为准。

## 8. 完整业务操作日志中心

位置：系统配置 -> 操作记录。

支持：

- 查看匹配日志、成功、失败、今日操作统计。
- 按关键词、操作类型、模块、执行结果、日期范围筛选。
- 查看日志详情，包括请求参数、错误信息、耗时和 IP。
- 按当前条件导出 CSV。
- 删除单条日志。
- 清空日志。清空前建议先导出备份。

## 9. 常见问题

### 9.1 页面打不开

检查服务是否启动：

```powershell
Invoke-WebRequest http://localhost:8091/api/cascade/all -UseBasicParsing
```

### 9.2 相机上报成功但页面无数据

检查相机是否已在系统配置中维护，设备上报的 `cameraCode` / `X-Device-Id` 必须能匹配系统中的相机编号。

### 9.3 未映射缺陷返回 422

这是正常保护机制。请到“系统配置 -> 相机缺陷映射”中补齐 `相机 + 产品 + 上报编码` 到标准缺陷类型的一对一映射。
