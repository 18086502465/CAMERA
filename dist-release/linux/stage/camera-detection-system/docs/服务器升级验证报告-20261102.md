## 五、升级操作规范（本次验证确认）

### 5.1 顺序不可颠倒

```bash
sudo systemctl stop camera-detection          # ① 必须先停
sudo cp new.jar /opt/.../time-bucket-demo.jar # ② 再换
sudo chown cdsys:cdsys /opt/.../time-bucket-demo.jar
sudo systemctl start camera-detection         # ③ 最后启
```

> ⚠️ **用 `cp` 覆盖运行中的 fat jar 会损坏服务**：JVM 从运行中 jar 读嵌套
> `BOOT-INF/lib/*.jar`，覆盖后偏移错乱 → 每个请求抛
> `NoClassDefFoundError: ch/qos/logback/classic/spi/ThrowableProxy`，
> 而 `systemctl status` 仍显示 `active`、NRestarts=0 —— 看着正常实则全错。
> 详见排查手册 §8.9.5。

### 5.2 判断"真的重启了"

```bash
systemctl show camera-detection -p ExecMainStartTimestamp -p MainPID
```
**时间戳与 PID 未变 = 根本没重启**，还在跑旧进程。

### 5.3 升级后必查项

```bash
# 1. 自检（当前 28 项）
sudo bash /opt/camera-detection-system/scripts/verify.sh

# 2. 启动日志无 ERROR
journalctl -u camera-detection --since '10 minutes ago' --no-pager | grep -cE ' ERROR '

# 3. 新功能接口可用
curl -s -H "Authorization: Bearer $TOKEN" \
  http://127.0.0.1:8091/api/v1/system/server/metrics | head -c 200
```
